# 📝 Multi-Image Text Extractor to DOCX

A fast, clean Streamlit web application that allows users to upload multiple images (JPEG, PNG, etc.), automatically extracts the text using Tesseract OCR, and bundles everything into a single, beautifully organized Microsoft Word (`.docx`) file with proper page breaks.

🚀 **Live Demo:** [ramerlabs-image-to-docx-converter.streamlit.app](https://ramerlabs-image-to-docx-converter.streamlit.app/)

## ✨ Features
* **Batch Processing:** Upload multiple images at once.
* **Layout Awareness:** Configured to read text left-to-right in multi-line paragraph blocks.
* **Instant DOCX Generation:** Download a structured `.docx` file containing all your text, automatically split with page breaks per image.
* **Sidebar CTA:** Integrated branding for your custom app agency.
